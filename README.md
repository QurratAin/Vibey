# Vibey
Soundscapes for every moment

**Vibey** is a lightweight, progressive web app that lets you create custom ambient sound mixes. Whether you need to focus, fall asleep, or just set the mood, Vibey gives you complete control over your sonic environment.

🔗 **Try it here:** [https://qurratain.github.io/Vibey/](https://qurratain.github.io/Vibey/)
